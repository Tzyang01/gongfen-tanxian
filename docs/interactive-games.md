# 十單元互動遊戲

## 設計與教學界線

在原有課程、引導學習及逐題練習之外，首頁和各單元增加遊戲入口，不以測驗解鎖。每款遊戲三關，重玩會使用另一組題目種子。所有互動使用點按、滑桿或數字輸入，鍵盤也可操作；不計時、不扣生命。

| 單元 | 遊戲 | 操作與教學目標 |
| --- | --- | --- |
| 1 | 森林小店長 | 貨號排序、百十個位付款、百元不足時換成十元 |
| 2 | 積木機器人工廠 | 合十進位、拆十退位、比較兩個二位數；判定包含換十操作 |
| 3 | 小小木工師傅 | 移動尺的零點、按指定長度定位切割線；畫面為示意公分 |
| 4 | 失物偵探社 | 全體與部分關係、求缺少量、用加法驗算 |
| 5 | 森林澆水隊 | 用同一杯子裝滿兩個容器；外形高矮不能代表容量 |
| 6 | 動物巴士出發 | 連加、連減、加減混合；每站承接前一站人數 |
| 7 | 點心派對廚房 | 2、5、4 個一組，擺盤並求總數 |
| 8 | 星光列車長 | 時分針連動、設定時間、計算經過時間 |
| 9 | 螢火蟲燈光秀 | 3、6、7 的乘法，用已知幾組加上新增幾組 |
| 10 | 動物新家鋪地板 | 用同樣大小方格完整鋪面，比較較大、較小與相同 |

每關作答錯誤或要求提示後，該關記為「協助後完成」。紀念章鼓勵完成探險，不代表課程精熟；家長報告分開顯示最近一輪的獨立完成關數。沿用既有課程精熟規則，不因遊戲完成而代替課程測驗。

## 孩子看得懂的文字

遊戲指令以短句和具體動作呈現；每款遊戲提供可重播、使用另一組數字的「先看怎麼玩」示範。必要課程詞彙用例子說明，例如用「兩部分加起來，看看能不能回到全部」解釋驗算。一般練習新增「聽這一題」，可一起讀出目前提示。語音由瀏覽器提供，聲音與支援程度依裝置而異。

先看示範也記為協助完成。一般練習前兩次答錯提供方法提示，第三次才顯示完整說明。引導練習的答案位置不再固定第一個，模型答案只在完成該步驟後顯示。

修正一般測量差值題的雙尺圖、個別單位的等長比較圖、兩步驟題的事件圖與面的直接比較條件，避免圖像洩漏答案或文字引起誤解。

## 程式模組

- `dist/island-games-engine.js`：純函式題目、狀態轉移、操作與答案判定。
- `dist/island-games.js`：獨立遊戲畫面、語音委派、操作事件、紀錄及家長摘要。
- `dist/island-games.css`：遊戲樂園、操作區與響應式版面。
- `dist/app.js`：現有頁面切換、單元入口與學習者連結。
- `tests/island-games.test.mjs`：十單元所有種子合法解、空白不能通關、換十守恆、兩步驟承接及防重複完成。

紀錄保存在 `math-island-games-v1:<profileId>`，只在三關完成後保存。重新整理會保留已完成紀念章，未完成回合則重新開始；不同裝置不會自動同步。這與原本課程、適性學習的 storage key 分開。

## 參考來源

依官方介紹研究教學互動方式，程式碼、介面和題目為本專案實作：

- [Number Pieces](https://www.mathlearningcenter.org/apps/number-pieces)：位值積木的合併與拆分。
- [Toy Shop Money](https://www.topmarks.co.uk/money/toy-shop-money)：付錢情境與難度分層。
- [Measuring in Centimetres](https://www.topmarks.co.uk/maths-games/measuring-in-cm)：量尺起點。
- [Thinking Blocks](https://www.mathplayground.com/thinkingblocks.html)：部分與全體的圖像化。
- [Teaching Clock](https://www.topmarks.co.uk/time/teaching-clock)：時分針連動。
- [Area Builder](https://phet.colorado.edu/en/simulations/area-builder)：方格組合與面的大小。

## 驗收方式

執行 `npm test` 和前端 JavaScript 語法檢查；再用本機 HTTP 伺服器進行十款遊戲全部三關的真實瀏覽器操作、空白提交、完成後重新整理、不同角色隔離、既有課程入口、平板與窄螢幕版面檢查。瀏覽器模擬不代表已在實體 iPad / Safari 上驗收。
